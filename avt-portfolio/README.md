## Getting Started

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

Open `index.html` in your browser, or run it with the **Live Server** extension in VS Code.

## Deployment

Hosted for free with **GitHub Pages**:

1. Push the project to GitHub.
2. Go to **Settings → Pages**.
3. Select the `main` branch and `/ (root)`, then **Save**.

Your site will be live at `https://<your-username>.github.io/<your-repo>/`.

## Customisation

| To change… | Edit |
|---|---|
| Colours and fonts | `:root` variables in `styles.css` |
| Photos and logo | Files in `assets/` |
| Skills, experience, projects | The matching sections in `index.html` |
| Social links | Add an `href` to each `<a class="social">` in the footer |
